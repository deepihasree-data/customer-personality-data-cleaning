# Customer Personality Data Cleaning

## Project Overview

This project focuses on cleaning and preprocessing the Customer Personality Analysis dataset using Python and Pandas.

The objective is to identify and handle missing values, duplicate records, inconsistent formats, incorrect data types, and non-uniform column names.

## Tools Used

- Python
- Pandas
- Google Colab
- GitHub

## Dataset

Customer Personality Analysis dataset.

The dataset contains customer demographic information, purchasing behavior, campaign responses, and spending information.

## Data Cleaning Steps

The following preprocessing steps were performed:

1. Loaded the raw dataset using Pandas.
2. Inspected the dataset structure and data types.
3. Checked for missing values.
4. Handled missing values.
5. Checked and removed duplicate records.
6. Standardized column names.
7. Converted date columns into a consistent date format.
8. Checked and corrected data types.
9. Identified and handled invalid values.
10. Exported the cleaned dataset as a CSV file.

## Deliverables

- `customer_personality_data_cleaning.ipynb` – Complete Python/Colab notebook containing the data cleaning process.
- `customer_personality_cleaned.csv` – Final cleaned dataset.

## Summary of Changes

The raw dataset was inspected and cleaned using Pandas. Missing values, duplicate records, inconsistent column names, date formats, and data types were checked and handled where required. The cleaned dataset was then exported into a new CSV file for further analysis.

## Conclusion

The dataset is now cleaner, more consistent, and ready for further analysis or machine learning applications.
